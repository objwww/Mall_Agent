# Skill 技能热更新验收说明

Skill 不是监控中的装饰字段：当前正文会附加到模型系统提示词，并和模型、Prompt、工具协议一起冻结进诊断快照。在途诊断继续使用启动时版本，新诊断使用切换后的版本。

| 操作 | 接口 | 请求正文 |
|---|---|---|
| 查看历史 | `GET /internal/v1/skills?limit=50` | 无 |
| 查看当前正文 | `GET /internal/v1/skills/current` | 无 |
| 发布并启用 | `POST /internal/v1/skills` | `{"version":"v2","instructions":"..."}` |
| 激活或回滚 | `POST /internal/v1/skills/v1/activate` | 无 |

所有接口使用 `Authorization: Bearer <AGENT_CONTROL_API_KEY>`，响应带 `X-Trace-Id`，日志仅记录版本和正文长度，不打印技能正文。
