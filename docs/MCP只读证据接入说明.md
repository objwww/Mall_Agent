# MCP 只读证据接入说明

## 已实现的闭环

MallAgent 启动时完成 `initialize`、`notifications/initialized` 和 `tools/list`，确认管理员配置的唯一白名单工具存在并声明只读。诊断时，系统把工单锚点作为固定参数调用该工具，将返回文本保存为带来源类型的真实证据；调用失败会记录为“证据不可用”，不会伪造结果。

MCP 证据采集器会进入运行时真实工具清单，因此工具摘要随实际接入变化，并被钉在诊断版本快照中。外部工具返回内容始终按不可信数据处理，不能覆盖系统提示词、授权或审批要求。

## 安全边界

- 远程连接只允许 HTTPS 且必须配置访问令牌；本机联调可使用 HTTP。
- 模型不能指定服务地址、工具名、参数名，也不能调用未配置工具。
- 不接入退款、订单状态修改、审批等写工具；资金动作继续走现有人工审批和独立验证链。
- 单次响应文本上限 64 KiB，所有请求都有超时。
- 日志只记录请求编号、工具名和结果长度，不输出令牌与完整证据。

## 验收方法

1. 启动只读 MCP 服务并配置一个 Profile。
2. 启动 MallAgent；若工具不存在或未声明只读，进程应拒绝启动。
3. 从管理端“运行工具清单”确认新增的 `evidence.mcp_*` 项和新摘要。
4. 创建带真实订单号或 TraceId 锚点的工单，确认 MCP 收到固定参数。
5. 查询诊断事件，确认存在该来源证据；停止 MCP 后再次诊断，确认结果为证据不可用而非假数据。
