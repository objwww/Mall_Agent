# MallAgent 运行配置

## 双 Agent 模型隔离

CaseLab 造题 Agent 与 MallAgent 工单处理 Agent 的职责和模型必须隔离：

- `CASE_AUTHOR_MODEL_ID`：造题 Agent 的模型标识，仅用于启动时校验隔离关系
- `AGENT_LLM_INITIAL_MODEL_ID`：MallAgent 首选处理模型
- 两者相同会拒绝启动，防止造题方同时看到处理提示词、工具和审批上下文

## 必填配置

首次部署先执行 `sql/001_mallagent_runtime_schema.sql`。MallAgent 的证据库通常指向商城业务库，运行库保存诊断、审批、执行、事件及提示词；两者可使用同一实例，但账号应按实际查询和写入范围授权。

| 配置 | 说明 |
| --- | --- |
| `AGENT_RUNTIME_JDBC_URL` | Agent 状态库连接 |
| `AGENT_RUNTIME_DB_USER` / `AGENT_RUNTIME_DB_PASSWORD` | 状态库账号密码 |
| `AGENT_MALL_BASE_URL` | 商城内部接口地址 |
| `AGENT_MALL_TENANT_ID` | 租户标识 |
| `AGENT_MALL_API_KEY` | 商城内部接口密钥 |
| `AGENT_CONTROL_API_KEY` | Agent 控制接口密钥 |
| `AGENT_LLM_PROFILES` | 可用处理模型标识，逗号分隔 |
| `AGENT_LLM_INITIAL_MODEL_ID` | 首选处理模型标识 |
| `CASE_AUTHOR_MODEL_ID` | CaseLab 造题模型标识，必须与处理模型不同 |
| `AGENT_OPERATIONS_BASE_URL` | mall_R 管理服务地址，用于真实 Run/Tool Call 上报 |
| `AGENT_OPERATIONS_INGEST_KEY` | 与 mall_R `AGENT_OPERATIONS_INGEST_KEY` 相同的采集密钥 |

可选配置：`AGENT_OPERATIONS_TIMEOUT_SECONDS` 默认 5 秒。

每个处理模型还需配置 `AGENT_LLM_<标准化标识>_BASE_URL`、`API_KEY`、`REMOTE_MODEL` 和可选的 `TIMEOUT_SECONDS`。

首次启动时数据库没有当前提示词，还必须配置 `AGENT_PROMPT_VERSION` 与 `AGENT_PROMPT_TEXT`。
首次启动时数据库没有当前技能，还必须配置 `AGENT_SKILL_VERSION` 与 `AGENT_SKILL_INSTRUCTIONS`。技能正文会真实附加到模型系统提示词；版本切换只影响新诊断。

## MCP 只读证据（可选）

`AGENT_MCP_PROFILES` 配置逗号分隔的连接标识。每个标识配置：

| 配置后缀 | 说明 |
| --- | --- |
| `ENDPOINT` | Streamable HTTP 地址；远程必须 HTTPS |
| `TOKEN` | 预先签发的 Bearer 令牌；远程必填，日志不会输出 |
| `TOOL` | 唯一允许调用的工具名 |
| `SOURCE_TYPE` | 证据类型，例如 `MCP_ORDER_TRACE` |
| `ARGUMENT` | 向工具传递业务锚点的参数名，例如 `traceId` |
| `TIMEOUT_SECONDS` | 超时秒数，默认 5，最大 30 |

例如标识 `order-trace` 会读取 `AGENT_MCP_ORDER_TRACE_ENDPOINT` 等配置。启动时会执行 MCP 初始化和 `tools/list`，只有配置白名单中的工具真实存在且声明 `readOnlyHint=true` 才能启动。当前不提供 MCP 写操作，也不让模型自由选择工具；每个工具作为固定证据采集器进入已有证据链和工具清单摘要。

`readOnlyHint` 只是服务端声明，不是安全边界，因此仍须同时使用专用只读 MCP 服务、最小权限令牌和工具白名单。当前只接收预先签发的令牌，不实现 OAuth 刷新流程。

## 控制接口

| 接口 | 用途 |
| --- | --- |
| `POST /internal/v1/diagnoses` | 创建诊断 |
| `GET /internal/v1/diagnoses/{id}` | 查询诊断 |
| `POST /internal/v1/diagnoses/{id}/approval` | 提交审批结果 |
| `GET /internal/v1/health` | 健康检查 |
| `POST /v1/runs` | 执行真实 Agent 离线评测用例 |

调用方必须携带控制 API 密钥。接口日志必须使用诊断编号、工单编号和 TraceId 关联，禁止输出 API 密钥、数据库密码、用户隐私及完整模型提示词。
