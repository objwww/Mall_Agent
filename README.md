# MallAgent

MallAgent 是商城工单的独立处理运行时，负责读取工单证据、调用处理模型、生成修复建议、等待审批、执行受控动作并验证恢复结果。它不是 CaseLab 造题 Agent，也不允许与造题 Agent 共用同一模型。

## 当前能力

- 工单理解、证据采集、推理、建议、审批、执行、恢复验证的持久化状态机
- OpenAI 兼容模型接口与模型健康切换
- 数据库版本化提示词热更新
- 退款重试、订单状态同步等受控商城内部接口
- 诊断创建、查询、审批与健康检查 HTTP 接口
- 超时恢复、未知结果查询、维护调度和异常告警

## 运行约束

- Java 17、MySQL 8+
- 必须配置 `CASE_AUTHOR_MODEL_ID`，且不得与 `AGENT_LLM_INITIAL_MODEL_ID` 相同
- 首次启动必须配置提示词版本和内容，后续由数据库 current 版本驱动热更新
- 涉及资金的动作默认关闭，必须同时通过管理员审批与运行开关

主要环境变量及启动步骤见 `docs/运行配置.md`。

首次部署先在运行库执行 `sql/001_mallagent_runtime_schema.sql`。该脚本可重复执行，只创建当前运行时真实使用的表。
